# Contributing

Issues that identify a statistical, timing, reproducibility, or documentation
problem are welcome. A useful report includes the exact command, environment,
observed result, expected result, and the smallest relevant artifact.

Changes to the frozen P1 evidence require special care:

1. Do not overwrite archived trials or transcripts.
2. Distinguish a correction from a new exploratory analysis.
3. Add a test for any code defect.
4. Regenerate affected tables, figures, hashes, and the paper.
5. State whether the correction changes a headline estimate or interpretation.

New strategies, datasets, models, or promotion rules are follow-on experiments.
They should use new seed ranges and a dated protocol rather than being folded
retroactively into the confirmatory sample.
